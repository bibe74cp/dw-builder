# BIML Compilation — README

## Overview

This folder contains instructions and helper scripts to **download**, **compile**, and **validate** the BIML file generated by DW-Builder API using **BimlExpress** (Visual Studio extension).

---

## Prerequisites

1. **Visual Studio 2022** (Community, Professional, or Enterprise)
   - Required workload: **SQL Server Data Tools (SSDT)**

2. **BimlExpress extension** (FREE)
   - Download: [BimlExpress for Visual Studio](https://www.varigence.com/bimlexpress)
   - Install via Visual Studio Extensions Manager or download `.vsix` installer

3. **DW-Builder API running**:
   ```powershell
   docker compose up -d api
   ```

4. **JWT Token** for API authentication:
   - Obtain token via `POST /api/v1/auth/login` endpoint
   - Store token in environment variable or pass to PowerShell script

---

## Step 1: Download BIML File

### Using PowerShell Script

**File:** `DownloadBiml.ps1`

```powershell
# Set JWT token (replace with your actual token)
$jwtToken = "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."

# Download BIML file
.\DownloadBiml.ps1 -JwtToken $jwtToken -OutputPath ".\MasterTemplate.biml"
```

**Output:**
- File `MasterTemplate.biml` saved in current directory

### Using curl (alternative)

```powershell
curl -H "Authorization: Bearer <JWT_TOKEN>" `
     -o MasterTemplate.biml `
     http://localhost:5000/api/v1/biml
```

## Step 3: Add BIML File to Project

1. In **Solution Explorer**, right-click on project → **Add** → **Existing Item**
2. Select `MasterTemplate.biml` file
3. File should appear in Solution Explorer with `.biml` icon

## Step 4: Compile BIML File with BimlExpress

### Method 1: Context Menu (Recommended)

1. Right-click `MasterTemplate.biml` in Solution Explorer
2. Select **"Expand Biml File"** (or **"Build Biml"** depending on BimlExpress version)
3. **Output Window** will show compilation progress

### Method 2: BimlExpress Menu

1. In Visual Studio top menu: **BimlExpress** → **Expand Biml File**
2. Select `MasterTemplate.biml` when prompted

## Step 5: Verify Generated SSIS Packages

### Expected Output

After successful compilation, the following `.dtsx` files should be generated in the project:

1. **`ETL_test_Customers.dtsx`**
   - SSIS package for `TestSource.dbo.Customers` table
   - Contains:
     - OLE DB Source (reads from `TestSourceDB.dbo.Customers`)
     - Script Component (calculates SHA-256 hash for `ChangeHashKey`)
     - OLE DB Destination (writes to `[test].[stg_Customers]`)
     - Execute SQL Task: `TRUNCATE TABLE [test].[stg_Customers]` (pre-load)
     - Execute SQL Task: `MERGE` from staging to landing
     - Execute SQL Task: Update `_meta.SourceTables` (sync status)

2. **`Master_TestSource.dtsx`** (if multiple tables configured)
   - Sequence container for all packages from `TestSource`
   - Executes packages sequentially
   - Event handlers for error logging

### Validation Checklist

- [ ] No compilation errors in Output window
- [ ] `.dtsx` files visible in Solution Explorer
- [ ] Packages can be opened in SSIS Designer
- [ ] Connection managers configured correctly:
  - `DW_Connection` → `DwBuilderDW` database
  - `TestSource_Connection` → `TestSourceDB` database
- [ ] Data Flow tasks have green validation icons

## Step 6: Configure Connection Managers (One-Time Setup)

BimlExpress generates connection managers with placeholder connection strings. Update them:

1. In **Solution Explorer**, expand **Connection Managers** folder
2. Double-click each connection manager and update:

**TestSource_Connection:**
- Connection string: `Data Source=localhost,1433;Initial Catalog=TestSourceDB;User ID=sa;Password=<SA_PASSWORD>;TrustServerCertificate=True`

**DW_Connection:**
- Connection string: `Data Source=localhost,1433;Initial Catalog=DwBuilderDW;User ID=sa;Password=<SA_PASSWORD>;TrustServerCertificate=True`

## Common Issues

### Issue 1: BimlExpress Not Installed

**Symptom:** No "Expand Biml File" option in context menu

**Solution:**
1. Install BimlExpress from [varigence.com/bimlexpress](https://www.varigence.com/bimlexpress)
2. Restart Visual Studio
3. Verify installation: **Extensions** → **Manage Extensions** → **Installed** → search "Biml"

---

### Issue 2: Compilation Errors

**Symptom:** Output window shows errors during Biml expansion

**Common causes:**
- Invalid SQL data types in `_meta.SourceFields`
- Missing connection string in BimlScript
- Syntax error in BimlScript template

**Solution:**
1. Check **Output** window for specific error message
2. Verify metadata in `_meta` schema:
   ```sql
   SELECT * FROM _meta.SourceFields WHERE SourceTableId = <ID>;
   ```
3. Re-download BIML file after fixing metadata
4. Re-compile

---

### Issue 3: Generated Packages Have Validation Warnings

**Symptom:** Yellow warning icons on Data Flow tasks

**Common causes:**
- Connection managers not configured
- Metadata column mapping mismatch

**Solution:**
1. Open package in SSIS Designer
2. Click **Data Flow** task → View **Warnings** in Error List
3. Fix connection managers (see Step 6)
4. Re-validate package: right-click → **Validate**

## Security Note

Connection strings contain `sa` credentials. **For test environment only.** In production:
- Use Windows Authentication or Managed Identity
- Store secrets in Azure Key Vault or SSIS Catalog environment variables
- Never commit connection strings to Git
